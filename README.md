# Heart-Disease-Predication
A production-ready machine learning application that predicts heart disease risk using advanced ensemble learning techniques. The system analyzes 13 key medical parameters to provide instant risk assessments with personalized health recommendations.

Technology Stack
Framework: Streamlit (web application)
ML Models: scikit-learn ensemble methods
Data Processing: pandas, numpy, StandardScaler
Best Model: Second Stacking Classifier combining GaussianNB, Logistic Regression, and SVC with Random Forest meta-learner
